## 📖 Описание программы

**SkyTracker** — учебный проект для хранения и визуализации данных о
авиамаршрутах. Программа позволяет *добавлять*, *редактировать* и
**удалять** записи о рейсах, а также строить простые отчёты.

> 💡 Проект создан в рамках выполнения практической работы ПР12.

### 🧩 Функциональность

- добавление маршрута;
- поиск по городу вылета/прилёта;
- экспорт отчёта в CSV;
- ~~поддержка старых форматов~~ (удалена в версии 2.0).
